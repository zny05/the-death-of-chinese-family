# Page 04 · 「熄火 · 丈夫反击」

> **页面属性**：分格页（**5 格，含 1 个横长条格**）
> **叙事功能**：唤醒序列收官 —— 丈夫第一次开口反击 + 妻子回怼 + 丈夫沉默
> **视觉重心**：⭐ **Panel 4.04 横长条格** —— 李斌闭眼特写，"被堵住嘴"的沉默。本页的"心电图最低点"
> **本页用到的锚点**：
> - 李斌：[base-v1](characters/character_李斌.json) + [疲惫闭眼](characters/character_李斌_疲惫闭眼.json)（Panel 4.02、4.03、4.04）
> - 妻子：[base-v1](characters/character_妻子.json) + [生气](characters/character_妻子_生气.json)（Panel 4.05）

## 总体构图与视觉重心

- **整体阅读方向**：左 → 右、上 → 下
- **页面整体氛围**：客卧内，窗帘已开，晨光完全涌入；从 Page 03 的"动作爆点"过渡到"声音交锋"再到"沉默"
- **视觉重心**：**Panel 4.04 横长条格** —— 全页唯一一条横向通栏，放在页面上半部（妻子回怼之后），用极宽极窄的画面表现"被压扁的丈夫"
- **节奏结构**：5 格采用 **2+2+1** 的节奏 ——

```
4.01  4.02          ← 李斌第一次坐起开口（2 格，动线 + 第一句台词）
4.03  4.04  4.05    ← 妻子反击 + 李斌沉默 + 妻子收尾（3 格：声音 → 沉默 → 声音）
```

→ 本页是"声音 → 沉默 → 声音"的三段式，Panel 4.04 是夹在两段声音中间的"无"

## 关键设计点

1. **"反击 → 沉默"是本页的核心母题** —— 李斌在本页第一次开口，却以"被堵住嘴"告终
2. **Panel 4.04 横长条格** 是全本第一个**"沉默帧"** —— 之后 Page 11、Page 13 还会复用这个手法
3. **5 格不平均分配** —— 上半部 2 格 + 下半部 3 格，上半部"短促"，下半部"绵长"，对应"反击被压制"的感觉
