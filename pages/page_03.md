## 总体构图与视觉重心

- **整体阅读方向**：左 → 右、上 → 下
- **页面整体氛围**：客卧内，从 Page 02 的"门外"切换到"门内"，光线从门缝光 → 窗帘后的阳光突然涌入
- **视觉重心**：**Panel 3.05 是本页最大的格**（横向通栏），定格"窗帘被扯开的瞬间"—— 模仿 Page 03 在全本里就是封面的预演
- **节奏结构**：8 格采用 **3+2+1+2** 的节奏 ——

```
3.01  3.02  3.03    ← 妻子冲入（3 格小图，动线建立）
3.04  3.05          ← 数落开始（3.05 是全页最大格，定格扯窗帘）
3.06  3.07  3.08    ← 切回李斌（3 格小图，反差收束）
```

## 关键设计点

1. **"声音 → 身体 → 声音"递进**：
   - 3.01 撞门（物理冲击）
   - 3.02 冲入（身体动作）
   - 3.03 第一句数落（声音回归）
   - 3.04 准备扯窗帘（身体预备）
   - 3.05 扯窗帘 + 大动作 + 台词同时（身体 + 声音高峰）
   - 3.06-3.08 切回李斌反应（无声）
2. **Panel 3.05 是 Page 03 的"心电图峰值"** —— 全页只有这一格用横向通栏
3. **李斌三联格（3.06/3.07/3.08）** 是"被光照醒但没睁眼"的连续镜头，建立**"外部动作 / 内部静止"**的反差
