## ⭐ 纯文字页的 SOP 支持规范（首次启用）

由于本页是**全本第一张纯文字排版页**（不画漫画图，只排文字），需要明确以下规则：

| 字段 | 处理方式 |
|---|---|
| **panel_id 命名** | `p17_textpage`（特殊命名，跳过 panel 编号） |
| **水印** | `P17-TEXT`（页面级唯一水印，与 splash 的 `P07-PN01` 区分） |
| **dialogue_or_narration** | **整页都是 narration**（作者声独白） |
| **sfx** | 无 |
| **prompt_en** | 仍走 Nano Banana 2，但 prompt **不是画漫画场景**，而是**生成一张"雾化房间照片底纹 + 文字排版"的合成图** |
| **文字内容** | 必须原文引用 `story/MC鲁迅的《李斌之死》剧情 - 原文.md` 倒数第 18-22 行的 5 段作者声 |

## 文字内容（原文引用）

> 我写过很多相亲中的人，爱情中的人。
> 但仔细回想，之前写的好像都比较特殊，比较黑色幽默。今天这篇我想写点细节，写点生活化的视角，写点绕开很多典型矛盾后，婚姻平淡日子里暗藏的洪流。
> 你会发现这篇文章中，没有剧烈的争吵没有暴力的撕扯，没有歇斯底里，没有疯狂，也有任何超越认知的抽象与抗争。
> 那些有关精神之间的折磨，
> 才是细小而可怕的刺。
