## 总体构图与视觉重心

- **整体阅读方向**：左 → 右、上 → 下
- **页面整体氛围**：出门前紧张感，妻子多次进出画面（换装前后对比）
- **视觉重心**：**Panel 6.04（轻蔑 + "你凶我干嘛呀"表情）** —— 妻子情绪光谱中最冷的一档
- **节奏结构**：6 格采用 **2+2+2** 的节奏 ——

```
6.01  6.02    ← 快递码 + 给谁买衣服（开篇交代）
6.03  6.04    ← 出门装 + 轻蔑瞬间
6.05  6.06    ← 粉底自评 + 出门/李斌留在家
```

→ 每对格子构成一个"信息块"，3 个信息块堆叠出出门前的密度感
